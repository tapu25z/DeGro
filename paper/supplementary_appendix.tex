\section{Formal Details}
Let a structured formalization be $F=(V,D,C,q)$, where $V$ is a finite set of typed variables, $D$ contains domain restrictions, $C$ contains translated source constraints, and $q(V)$ is the target. Write
\[
  \mathrm{Sol}(F)=\{m\mid m\models D\land C\}.
\]
The target is determinate when all feasible assignments agree:
\begin{equation}
  \mathrm{Det}(F,q) \iff
  \forall m_1,m_2\in\mathrm{Sol}(F),\ q(m_1)=q(m_2).
  \label{eq:det}
\end{equation}
For two disjoint renamings $V^{(1)}$ and $V^{(2)}$, define
\begin{equation}
  \Phi(F,q)=F^{(1)}\land F^{(2)}\land
  q(V^{(1)})\neq q(V^{(2)}).
  \label{eq:phi}
\end{equation}

\paragraph{Witness equivalence.}
Assuming semantics-preserving compilation, $\Phi(F,q)$ is satisfiable exactly when two feasible assignments disagree on $q$. A satisfying assignment projects to the two witnesses; conversely, any such pair satisfies Eq.~\eqref{eq:phi}. Hence, if $F$ is satisfiable and $\Phi(F,q)$ is unsatisfiable, Eq.~\eqref{eq:det} holds. The initial satisfiability check is necessary because an inconsistent $F$ would otherwise yield a vacuous certificate.

\paragraph{Repair gate.}
For candidate constraint $c$ and a frozen set $\mathcal{R}$ of permitted domain-semantics rules,
\begin{align}
\mathrm{Accept}(c)\iff{}&\mathrm{Compiles}(c)\land
\mathrm{Grounded}(c,P,\mathcal{R})\nonumber\\
&\land\mathrm{SAT}(F\land c)\land\neg(F\models c)
\land\mathrm{Det}(F\land c,q).
\label{eq:accept}
\end{align}
Thus every accepted edit is supported, consistent, novel, and target-sufficient. If neither of two proposals passes, the original $F$ is preserved. Exact-span provenance is an auditable proxy, not a proof of semantic equivalence.

\section{Reference Algorithm and Trusted Boundary}
The bounded controller performs:
\begin{enumerate}
  \item parse one typed \status{ModelSpec} and reject unsupported expressions;
  \item check $\mathrm{SAT}(F)$, then $\Phi(F,q)$;
  \item if ambiguous, record two target-divergent witnesses;
  \item request one grounded constraint or \status{abstain};
  \item apply Eq.~\eqref{eq:accept}, stopping after at most two proposals.
\end{enumerate}
The restricted parser, typed compiler, Z3, and deterministic gate form the trusted boundary; the language model does not. The parser rejects undeclared identifiers, arbitrary calls, attribute access, and unsupported operators. Both solving and verification consume the same normalized specification. Logs retain initial and final states, witnesses, proposals, cited spans, rejection reasons, model configuration, and prompt hashes.

\section{Controlled Paired Evaluation}
For a validated gold specification $F^*=\{c_1,\ldots,c_k,c^*\}$, define $F^-=F^*\setminus\{c^*\}$. An item is retained only when $F^*$ is satisfiable and target-determinate while $F^-$ is satisfiable and target-ambiguous. Two source conditions share exactly $F^-$:
\begin{itemize}
  \item \textbf{Omission:} the source retains the sentence supporting $c^*$; grounded repair is correct.
  \item \textbf{Underspecified:} that sentence is removed; abstention is correct.
\end{itemize}
The solver state is identical within each pair, so ambiguity alone cannot reveal the label. The 120-pair confirmatory set is disjoint from the 80-pair pilot and 100-pair development sets and was frozen before outcome inspection. It contains rank-deficient systems (20), linear separation (20), moment problems (40), Chinese-remainder reconstruction (20), and graph path sums (20).

All four policies receive the same source, $F^-$, target, schema, and two-attempt budget. Self-review receives neither verdict nor grounding rule; grounded self-review adds grounding; determinacy-guided adds the solver verdict; \method{} receives both. Both models use medium reasoning effort and temperature 1.0, giving 960 complete records per model. RSR measures correct repair on omission cases, CAR correct abstention, and $\mathrm{FDA}=(\mathrm{RSR}+\mathrm{CAR})/2$. Confidence intervals resample pairs; paired tests use exact two-sided McNemar tests with Holm correction across the two model-specific primary tests.

\section{Natural-Error Study}
Exactly one Structured SymCode formalization was generated per problem and reused across methods. Cohort membership was frozen from parse, compiler, and solver states before annotation or repair-outcome inspection. Blinded annotation packets omitted the determinacy verdict, witness, repair, method, and answer outcome.

Two reviewers inspected all 292 MATH-500 and 503 ALG514 final AI-assisted labels. Because separate pre-discussion human labels were not retained, we claim two-person verification, not independent double annotation. Labels are \status{correct}, \status{missing-constraint}, \status{wrong-constraint}, \status{extra-constraint}, \status{wrong-domain}, \status{wrong-target}, \status{computational-error}, and \status{other}; ambiguity itself never determines the label.
