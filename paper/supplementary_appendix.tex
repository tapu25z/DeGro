\section{Formal Details}
Let a structured formalization be $F=(V,D,C,q)$, where $V$ is a finite set of typed variables, $D$ contains domain restrictions, $C$ contains translated source constraints, and $q(V)$ is the target. Write
\[
  \mathrm{Sol}(F)=\{m\mid m\models D\land C\}.
\]
The target is determinate when all feasible assignments agree:
\begin{equation}
  \mathrm{Det}(F,q) \iff
  \forall m_1,m_2\in\mathrm{Sol}(F),\ q(m_1)=q(m_2).
  \label{eq:det}
\end{equation}
For two disjoint renamings $V^{(1)}$ and $V^{(2)}$, define
\begin{equation}
  \Phi(F,q)=F^{(1)}\land F^{(2)}\land
  q(V^{(1)})\neq q(V^{(2)}).
  \label{eq:phi}
\end{equation}

\paragraph{Witness equivalence.}
Assuming semantics-preserving compilation, $\Phi(F,q)$ is satisfiable exactly when two feasible assignments disagree on $q$. A satisfying assignment projects to the two witnesses; conversely, any such pair satisfies Eq.~\eqref{eq:phi}. Hence, if $F$ is satisfiable and $\Phi(F,q)$ is unsatisfiable, Eq.~\eqref{eq:det} holds. The initial satisfiability check is necessary because an inconsistent $F$ would otherwise yield a vacuous certificate.

\paragraph{Repair gate.}
For candidate constraint $c$ and a frozen set $\mathcal{R}$ of permitted domain-semantics rules,
\begin{align}
\mathrm{Accept}(c)\iff{}&\mathrm{Compiles}(c)\land
\mathrm{Grounded}(c,P,\mathcal{R})\nonumber\\
&\land\mathrm{SAT}(F\land c)\land\neg(F\models c)
\land\mathrm{Det}(F\land c,q).
\label{eq:accept}
\end{align}
Thus every accepted edit is supported, consistent, novel, and target-sufficient. If neither of two proposals passes, the original $F$ is preserved. Exact-span provenance is an auditable proxy, not a proof of semantic equivalence.

\section{Reference Algorithm and Trusted Boundary}
The bounded controller performs:
\begin{enumerate}
  \item parse one typed \status{ModelSpec} and reject unsupported expressions;
  \item check $\mathrm{SAT}(F)$, then $\Phi(F,q)$;
  \item if ambiguous, record two target-divergent witnesses;
  \item request one grounded constraint or \status{abstain};
  \item apply Eq.~\eqref{eq:accept}, stopping after at most two proposals.
\end{enumerate}
The restricted parser, typed compiler, Z3, and deterministic gate form the trusted boundary; the language model does not. The parser rejects undeclared identifiers, arbitrary calls, attribute access, and unsupported operators. Both solving and verification consume the same normalized specification. Logs retain initial and final states, witnesses, proposals, cited spans, rejection reasons, model configuration, and prompt hashes.

\section{Controlled Paired Evaluation}
For a validated gold specification $F^*=\{c_1,\ldots,c_k,c^*\}$, define $F^-=F^*\setminus\{c^*\}$. An item is retained only when $F^*$ is satisfiable and target-determinate while $F^-$ is satisfiable and target-ambiguous. Two source conditions share exactly $F^-$:
\begin{itemize}
  \item \textbf{Omission:} the source retains the sentence supporting $c^*$; grounded repair is correct.
  \item \textbf{Underspecified:} that sentence is removed; abstention is correct.
\end{itemize}
The solver state is identical within each pair, so ambiguity alone cannot reveal the label. The 120-pair confirmatory set is disjoint from the 80-pair pilot and 100-pair development sets and was frozen before outcome inspection. It contains rank-deficient systems (20), linear separation (20), moment problems (40), Chinese-remainder reconstruction (20), and graph path sums (20).

All four policies receive the same source, $F^-$, target, schema, and two-attempt budget. Self-review receives neither verdict nor grounding rule; grounded self-review adds the exact-span grounding rule but receives neither a solver verdict nor witnesses; determinacy-guided adds the typed ambiguity verdict without grounding; \method{} receives both the verdict and grounding rule. The main comparison does not expose witness values to the repair model. GPT-OSS 20B and 120B use medium reasoning effort and temperature 1.0, giving 960 complete records per model. The post-hoc Nemotron 3 Nano 30B addition uses the same frozen data, prompts, methods, temperature, and API \code{think=medium} request, yielding 960 complete records; this does not establish equal internal reasoning budgets. FDA is the primary outcome; RSR measures correct repair on omission cases, CAR measures correct abstention on underspecified cases, and $\mathrm{FDA}=(\mathrm{RSR}+\mathrm{CAR})/2$. Confidence intervals resample pairs; paired tests use exact two-sided McNemar tests with Holm correction across the two GPT-OSS tests. The later Nemotron test is exploratory and reported separately.

\section{Exploratory Source-Coverage Refinement}
We inspected only the 80-pair development outputs before defining one candidate prompt. The refinement instructs the model to compare every stated condition algebraically against the current formalization, consider indirect relations among non-target variables, distinguish ambiguity of the current formalization from adequacy of the source, and treat listed domains as already enforced. Labels, gold targets, missing constraints, and pair identifiers are absent from the prompt. The candidate was frozen before any new-test inference.

The original 300 records exhaust the solver-compatible MIRA pool used by this study. We therefore generated a separate 100-pair synthetic stress set, with 25 pairs each for linear separation, graph path sums, Chinese-remainder reconstruction, and rank-deficient linear systems. All 200 gold actions pass the released scorer; all source strings are unique, and none exactly matches the original 300-pair source strings. Template similarity remains, so this set is not an external benchmark or an additional MIRA test. Both prompts were run concurrently with temperature 1.0 and API \code{think=medium}; inference retained the first valid response and never retried by score.

\section{DRAW-Paired: Natural-Source Paired Evaluation}
DRAW-Paired uses only the 600 training and 200 development problems of DRAW-1K~\cite{upadhyay2017derivations}. Its 200 test problems are not used. One duplicate source identifier and 200 single-equation problems are excluded; the remaining 599 systems have a target-critical deletion verified by the solver. The initial seeded 300-pair cohort contains 223 training-derived and 77 development-derived sources. A source-disjoint, seeded extension selects 50 of the remaining 67 unflagged proposals (37 training-derived and 13 development-derived), yielding 350 pairs and 700 cases. Each source contributes an omission case and an underspecified case with identical retained equations and target. Variables are real-valued and full-system target values are checked against published gold solutions. These are injected gold-equation omissions, not a natural model-error cohort.

The author confirmed manual review of the initial 300 proposed spans and deletions after provisional inference. Final validation detected two incorrectly segmented title abbreviations; both supporting sentences were corrected and all 16 case--policy records per model for those two pairs were rerun. Other responses were retained and rescored. The extension was selected after the initial outcomes and locked before its own inference, but its 50 span/deletion reviews are still pending. Thus the combined main result is provisional, not fully human-verified or preregistered. No independent annotation or agreement statistic is claimed. All original 300-pair outputs remain archived; merging adds 400 extension records per model without replacing those outputs. The main paper reports all four policies, not only the favorable comparison.

Each model has 2,800 complete unique records under temperature 1.0 and API \code{think=medium}. Primary tests compare DeGro with grounded self-review on FDA using exact McNemar, 10,000 pair-cluster bootstrap resamples, and Holm adjustment across three models. The reviewed initial dataset, extension review packet, mixed-review combined dataset, corrected raw responses, complete outputs, and analysis JSON retain separate provenance.
